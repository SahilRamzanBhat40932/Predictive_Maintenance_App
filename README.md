# 🏭 Predictive Maintenance using Machine Learning

## Overview

This project predicts whether an industrial machine is likely to fail based on operational parameters using a Random Forest Classifier.

The application is developed using **Python**, **Scikit-learn**, and **Streamlit**.

---

## Features

- Predict Machine Failure
- Random Forest Classification
- Prediction Confidence
- Feature Importance Visualization
- Interactive Streamlit Dashboard

---

## Dataset

AI4I 2020 Predictive Maintenance Dataset

---

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Plotly
- Joblib

---

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
